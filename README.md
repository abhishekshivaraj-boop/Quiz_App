# 🎯 Quick Quiz App

A lightweight, responsive web application built using **HTML5**, **CSS3**, and **JavaScript (ES6+)**. Test your knowledge, track your scores, and save your high scores locally!

---

## ✨ Features

* **Interactive Gameplay:** Dynamic question loading with immediate visual feedback (green for correct, red for incorrect).
* **Score Tracking:** Real-time HUD showing current score and progress (e.g., Question 1/3).
* **Local High Scores:** Saves your top scores locally in your browser using `localStorage`.
* **Responsive Layout:** Clean CSS flexbox styling designed to look great on desktop and mobile screens.
*live:https://abhishekshivaraj-boop.github.io/Quiz_App/index.html
---

## 🛠️ Built With

* **HTML5** - Page structure and markup
* **CSS3** - Custom styling, CSS variables, and layout
* **JavaScript (Vanilla ES6)** - Quiz logic, DOM manipulation, and `localStorage` integration
